# Soil Bearing Capacity Calculator

This project calculates the Ultimate and Safe Bearing Capacity of soil using Terzaghi's Bearing Capacity Theory.

## 📌 Features
- Calculates Ultimate SBC
- Calculates Safe SBC (FOS = 3)
- Based on soil parameters:
  - Cohesion (c)
  - Unit weight (γ)
  - Depth of foundation (Df)
  - Width of footing (B)
  - Angle of internal friction (φ)

## 🛠️ Formula Used
Terzaghi Bearing Capacity Equation:

qu = cNc + γDfNq + 0.5γBNγ

## ▶️ How to Run
1. Install Python
2. Run:
   python sbc_calculator.py

## 📊 Example Input
c = 0  
γ = 18  
Df = 1.5  
B = 2  
φ = 30  

## 📈 Output
Ultimate SBC and Safe SBC
